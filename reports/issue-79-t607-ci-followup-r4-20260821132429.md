## 指摘事項

- 診断: production path identity bugではなくtest fixtureのplatform mismatchである。Windowsではfixtureとruntime semanticsが一致し、Linuxでは`C:\\repo`がPOSIX repository rootとして一致しなかった。
- 修正: host semanticsを明示し、Windowsでは`C:\\repo`と`/C:/repo`、POSIXでは`/repo`をrepository root・workspace URI・document pathへ一貫適用した。descriptorのsemanticsとrepository-relative `src/😀.ts`も明示assertする。
- 同期: workspace/PR stateを直接Mapへ挿入せず、async repository `save`をawaitしてからactual state providerを呼ぶ。固定sleepやtiming依存は追加していない。
