## Purpose / scope

T405の要求に従い、Review Contexts ViewとGitHub PRコンテキスト操作をproduction runtimeへ接続した。

実装範囲:

- 現在PR、現在branch、保存済みopen/closed PR、workspace contextのReview Contexts表示projection
- PR再検出
- GitHub再接続
- PR diff/cache再取得
- PR layer ON/OFF
- Review Contextsからの表示削除
- closed PRを含むexact base/head PR diff表示
- 保存済みrepository context列挙
- VS Code manifestのactivation/command/menu/configuration登録

非対象:

- T406が担当するGitHub未認証公開repository、401/403/404/429、network断、patch欠落、複数PR、closed PRの統合試験追加
- task trackingの直接更新
- merge

- closed PRの既定layerは無効
