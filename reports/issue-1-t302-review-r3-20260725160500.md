## レビュー観点

- Windows予約デバイス名と拡張子付き名称を拒否するか
- POSIXで同じ名称を不要に拒否しないか

## 確認結果

### Local Git runtime

- `createNodeLocalGitAdapter()`が1つのoptionsからexecutorとblob readerを生成する
- `executable`と`timeoutMs`を両方へ渡す
- `maxBufferBytes`はmetadata executorにだけ渡す
- PATHを空にしたintegration testでrevision確認、`ls-tree`、`cat-file blob`の3commandが同じfake executableを使用した
- public barrelとconsumer fixtureからfactoryを利用できる

### Windows path

- `CON`、`PRN`、`AUX`、`NUL`をcase-insensitiveで拒否する
- `COM1`〜`COM9`、`LPT1`〜`LPT9`を拒否する
- `con.txt`、`COM1.log`等もbasename判定で拒否する
- nested segmentにも同じ判定を適用する
- POSIX semanticsではこれらを通常のfile名として維持する
- URI encode時にも共有validator経由で拒否する

### 設計書

- 恒久設計は`doc/design/vscode-review-range-tracker-design.md` rev2の1fileだけに統合した
- task専用補遺を削除した
- 機能ごとにレビュー操作、context、path、diff文書、Local Git、変更追従、進捗、architecture、永続化、error、testを整理した
- task identifierと実装phase案を含まない
- 同系列設計fileがmain 1件だけであることをunit testで固定した
