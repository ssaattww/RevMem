## 検出・修正済みfinding

### R1: unpaired surrogateでURI round-tripが非可逆になる

- 重要度: High
- 内容: JavaScript文字列にunpaired UTF-16 surrogateがあると、`Buffer.from(..., "utf8")`がreplacement characterへ変換し、encode/decode後のdescriptorが入力と一致しない
- 対応: valid surrogate pairのround-trip testと、末尾high、単独low、high直後の非low surrogateを拒否するtestを先行追加した
- 初回修正の末尾high判定漏れはCI Run #714で再現し、条件修正後のRun #720で解消した
- 状態: 修正済み

### R2: control character正規表現がlint違反になる

- 重要度: Medium
- 内容: URI fieldの制御文字検査にcontrol character rangeを含む正規表現を使い、ESLint `no-control-regex`で停止した
- 対応: 文字コード走査へ変更し、検査挙動を維持した
- 状態: 修正済み

### R3: T302 testが通常suiteへ未接続になる可能性

- 重要度: Medium
- 内容: repositoryのunit test scriptは対象fileを明示列挙するため、test source追加だけでは通常CI実行対象にならない
- 対応: URI/provider、Local Git source、VS Code adapter、Unicode回帰を`test:unit`と`test:t302`へ明示接続し、実Gitrevision testは既存Git統合suiteへ追加した
- 状態: 修正済み
