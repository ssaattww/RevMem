## 確認結果

### Architecture

- 設計書rev3にvalidatorと同一のlayer dependency tableがある
- unit testが設計tableと`allowedLayerDependencies`をparseして比較する
- UI層はcore/application/uiだけへ依存する
- UI command、view、providerはruntime adapterを直接生成・importしない
- Composition Rootがruntime adapter、application service、UI adapterを組み立てる

### UI仕様

- Current Context Viewの表示項目と再検出・再接続・再計算操作を復元した
- PR Progress Viewの分類、file表示、既定sort、sort候補を復元した
- Review Contexts Viewのopen/closed PR、branch、workspace、layer/cache/表示削除を復元した
- 表示削除と履歴削除を分離した
- 重要fragmentを設計contract testで固定した

### Local Git construction

- `LocalGitAdapter`はexecutorとblob readerの2境界を必須とする
- implicit `NodeGitBlobReader`生成経路はない
- Node runtimeは`createNodeLocalGitAdapter()`でexecutable・timeoutを共有する
- type fixtureが1引数constructorをcompile errorとして固定する
- metadata-only testも明示的なblob boundaryを持つ

### Timeout error

- metadata timeoutは`GitCommandFailedError`となる
- invocation、partial output、timeout diagnosticを保持する
- exit codeは`-1`
- blob timeoutと同じerror familyを使用する
- executable未検出は`GitExecutableNotFoundError`のまま区別する

### 回帰

- package manifestのliteral backslash説明を既存contractどおり維持した
- URI、path semantics、missing/fatal、large blob、invalid UTF-8、actual VS Code URIのtestが成功した
- Build、Contract typecheck、Lint、Unit、Temporary Git、Mock GitHub、VS Code Extension Hostが成功した
