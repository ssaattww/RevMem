# ワークスペース設定を書き換えない表示切り替え

## 目的
「確認済みレイヤーを切り替え」は現在、表示の切り替えをワークスペース設定に保存します。設定ファイルが版管理されている場合、表示を変えただけで差分が生じます。表示切り替えを維持しながら、この書き込みをなくします。

## 実装方針
既存設定は初期値として読み取ります。操作で変えた表示状態は拡張機能のワークスペース状態に保存し、設定ファイルとは分離します。

## 実装詳細
切り替え操作とエディターの装飾更新は同じ表示状態を参照します。既存の設定ファイルの削除・移行や、そのほかの設定キーの変更は行いません。

## 完了条件
- 連続した2回の操作で表示が切り替わり、元に戻る。
- ワークスペースを開き直しても最後の選択が復元される。
- 設定ファイルが既にある場合は変更せず、ない場合は作らない。

## テスト内容
既存設定がある場合とない場合を隔離した作業領域で確認します。切り替え、再読み込み、ファイル内容および Git 差分の比較を行います。
