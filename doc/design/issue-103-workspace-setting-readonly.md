# 表示を切り替えてもワークスペース設定を変更しない

## 目的

「Global 確認済みレイヤーを切り替え」を押すと、現在は共有され得るワークスペース設定へ書き込むため、設定ファイルが Git の差分に出ます。切り替えと再起動後の復元を維持し、拡張機能による設定ファイルへの書き込みだけをなくします。報告時の実際の差分がこの経路によるものかは未確認です。

## 実装方針

表示状態をワークスペース単位で一つにまとめます。トグルと通常エディターの装飾には、いずれもその同じ状態を渡します。

| 入力 | 採用する表示 |
| --- | --- |
| 初回起動 | 現在の有効な設定値。未指定なら既定の表示オン |
| トグル成功 | 直前の表示を反転 |
| 設定を変更せず再起動 | 拡張機能に保存した最後の表示 |
| 利用者が対象設定の有効値を変更 | 新しい設定値。停止中の変更も次の起動で適用 |
| 無関係の変更、または有効値が同じ編集 | 現在の表示を維持 |

## 実装詳細

- `reviewRange.showGlobalReviewed` は既存の設定 API から読むだけにします。`workspaceState` に「選んだ表示」と「その時点での有効な設定値」を保存し、起動時に設定値を比較します。既存設定ファイルの更新・移行・削除は行いません。
- トグルと対象設定の変更を順に処理します。設定の変更を先に反映してから後続のトグルを判定します。保存が成功してから状態を確定し、装飾と Global 表示を更新します。保存に失敗した操作は適用せず、エラーを通知します。後続操作は最後に確定した状態から処理します。
- 対象は通常エディターの Global 確認済み表示だけです。現在の Context や PR レイヤーの表示、他の設定、レビュー結果の保存は変えません。README と設定の説明に新しい保存先を明記し、従来との違いを `Design/BreakingChanges.md` に記録します。

## 完了条件

- 表示が切り替わり、閉じて開き直しても選択が復元される。対象設定を利用者が変更したときは、その値が優先される。
- 既存の設定ファイルはバイト単位で変化せず、存在しない設定ファイルは作られない。トグルによる Git 差分は増えない。
- 保存失敗や連続操作でも、トグルと装飾が同じ確定状態を示す。Context 由来の表示には影響しない。

## テスト内容

| 場面 | 確認すること |
| --- | --- |
| 設定ファイルのある一時フォルダー／ない一時フォルダー | トグルを実行。設定更新 API を使わず、ファイルのバイト一致または非生成と Git 差分なしを確認 |
| 複数フォルダーの一時ワークスペース | `.code-workspace` と既存の各フォルダー設定が変わらず、存在しないフォルダー設定も作られない |
| 有効値をオンにした状態で表示をオフにして再起動 | オフに復元。別ケースで停止中または起動中に対象設定を変更すると、新しい値になる |
| 連続トグル／無関係・同値の設定変更／保存失敗 | 反転の順序、不要な保存なし、失敗時の表示維持。Global 表示だけが変わることも確認 |

利用者の実環境は使いません。ファイル非変更の確認と、テストが利用者の設定編集を模擬する場面の前後比較は区別します。
